# Chok Dee Muay Thai

โชคดี มวยไทย

[![Test](https://github.com/Chris1112220/muay-thai-sessions/actions/workflows/test.yml/badge.svg)](https://github.com/Chris1112220/muay-thai-sessions/actions/workflows/test.yml)

A free website that builds a Muay Thai session from YouTube videos to fit the time you have.

## Development

```sh
npm ci
npm run typecheck
npm test
```

The v1 spec and its tickets live in `.scratch/muay-thai-sessions/`. Domain terms are in `GLOSSARY.md`, and decisions in `docs/adr/`.
